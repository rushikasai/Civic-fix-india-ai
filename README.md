# Civic-fix-india-ai
CivicFix India 🇮🇳

CivicFix India is an AI-powered civic assistance project that helps citizens organize and report local infrastructure problems.

Problem

Reporting potholes, overflowing garbage, and broken streetlights can be confusing when people do not know the correct reporting channel.

Solution

CivicFix India helps users:

- Describe and classify civic problems.
- Organize the incident location and details.
- Assess urgency and potential public impact.
- Prepare a structured complaint and identify possible reporting channels.

Technology

- Python
- Fetch.ai uAgents
- Agentverse
- Agent Chat Protocol (ACP)
- ASI:One

How to Test

1. Open the registered agent through ASI:One.
2. Describe a civic problem and provide its location.
3. Review the generated complaint and recommended next steps.

Safety and Limitations

CivicFix India does not claim that a complaint has been officially submitted unless a real reporting integration confirms successful submission.
